# Project Summary
NutriAI is an innovative application designed to assist users in managing their nutrition and meal planning. By leveraging advanced AI technologies, it offers personalized meal suggestions, dietary tracking, and analytics to enhance users' health and wellness. The platform integrates features such as meal logs, chat functionalities, and a user-friendly dashboard, making it an essential tool for anyone looking to improve their eating habits. Recent updates include a Saved Recipes page, enhanced photo storage capabilities for meal logging, significant performance optimizations, and the addition of profile editing features.

# Project Module Description
The project consists of several functional modules:
- **Frontend**: Built with React and TypeScript, it provides a responsive user interface for interacting with the application, now optimized with lazy loading and skeleton components.
- **Backend**: Utilizes Atoms Cloud for managing data and authentication services, now fully implemented with routers and data models.
- **AI Services**: Implements multiple AI models for features like meal suggestions and analytics, including `gemini-2.5-pro`, `gpt-5-chat`, `claude-4-5-sonnet`, and `gemini-2.5-flash-image`.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - For the backend, navigate to the `app/backend` directory and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```
2. **Build the Project**:
   - For the frontend, run:
     ```
     pnpm run build
     ```
3. **Run the Application**:
   - Start the backend server.
   - Serve the frontend application.
