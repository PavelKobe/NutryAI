# Legacy: Vite + shadcn (не для продакшена)

Этот каталог — **архив** прежнего SPA на Vite. С марта 2026 основной UI и деплой — **Next.js** в `app/web/`.

- Не запускайте и не деплойте эту версию без явной необходимости.
- Зависимости: `node_modules` в git не коммитятся (см. корневой `.gitignore`). Чтобы запустить архив локально: `npm install` или `pnpm install` внутри этой папки.
- Полезный код при переносе уже дублирован в `app/web` (страницы, компоненты, лендинг).
