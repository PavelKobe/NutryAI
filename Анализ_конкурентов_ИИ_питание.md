# Writing Outline
-   **Введение: Цель и методология анализа**
    -   Описать цель анализа: выявление ключевых игроков, их функционала и рыночных пробелов для разработки нового ИИ-приложения для здорового питания.
    -   Кратко изложить методологию: обзор рынка, детальный анализ конкурентов, выявление общих черт и уникальных предложений.
    -   *Написание: Прямое (без поиска)*
-   **Обзор рынка ИИ-приложений для здорового питания и ключевые игроки**
    -   Представить текущее состояние рынка ИИ-приложений в области диетологии.
    -   Выделить 3-5 наиболее заметных конкурентов или инновационных проектов.
    -   Кратко описать их общую концепцию.
    -   *Написание: Требуется поиск (рыночные данные, список конкурентов)*
-   **Детальный анализ функционала конкурентов и применение ИИ**
    -   Для каждого из выявленных ключевых конкурентов подробно описать их основные функции.
    -   Особое внимание уделить тому, как ИИ используется в их продуктах (например, персонализация рекомендаций, анализ данных, распознавание продуктов).
    -   Выделить сильные стороны каждого конкурента.
    -   *Написание: Требуется поиск (специфические функции, использование ИИ)*
-   **Выявление общих черт, уникальных предложений и рыночных пробелов**
    -   Систематизировать обнаруженные общие и уникальные функции конкурентов.
    -   Определить, какие функции являются "стандартом" в отрасли, а какие — уникальными преимуществами.
    -   Выявить "слепые зоны" рынка: функции, которые могли бы быть полезны пользователям, но отсутствуют у существующих игроков. Это и есть "чего не хватает".
    -   *Написание: Прямое (синтез на основе предыдущих данных)*
-   **Заключение и рекомендации для нового приложения**
    -   Сформулировать основные выводы из анализа.
    -   Предложить конкретные рекомендации по разработке функционала для нового приложения пользователя, учитывая выявленные рыночные пробелы и успешные практики конкурентов.
    -   Подчеркнуть потенциальные УТП (уникальные торговые предложения) для нового приложения.
    -   *Написание: Прямое (синтез, рекомендации)*
**Suggested Tone/Style:** Профессиональный, аналитический, информативный.

    *   Поддерживает: Раздел "Обзор рынка ИИ-приложений для здорового питания и ключевые игроки".
2.  **Поиск:** "[Название приложения 1] функционал ИИ обзор" и "[Название приложения 2] как работает ИИ в питании" (для 2-3 ключевых конкурентов)

    *   Поддерживает: Раздел "Детальный анализ функционала конкурентов и применение ИИ".
3.  **Поиск:** "инновации в приложениях для питания с ИИ 2026" ИЛИ "отсутствующие функции ИИ диетология рынок"

    *   Поддерживает: Раздел "Выявление общих черт, уникальных предложений и рыночных пробелов".
4.  **Поиск:** "сравнение персонализации ИИ в приложениях для здорового питания" ИЛИ "ИИ-модели для рекомендаций по питанию и диетам"

    *   Поддерживает: Раздел "Детальный анализ функционала конкурентов и применение ИИ", "Выявление общих черт, уникальных предложений и рыночных пробелов".
